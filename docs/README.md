## 🎯 프로젝트 개요

우아한테크코스 최종 코딩테스트를 대비하기 위한 연습용 프로젝트입니다.   
페어매칭관리 애플리케이션 프로그램을 구현합니다.

---

## 📝 구현 기능 목록

### 1. 기본 정보 설정
- [x] **기능 종류 입력**
  - 입력 안내 문구 출력
  - 입력
  - **예외 처리**
  - 빈값 / 공백 불가
  - 1~3 숫자 또는 Q
  - 예외 발생 시 에러 문구 출력, 재입력
- [x] **과정, 레벨, 미션 입력**
  - 입력 안내 문구 출력
  - 입력 (`,` 로 구분해서 입력)
  - **예외 처리**
    - 빈값 / 공백 불가
    - 3가지 요소
    - 존재하는 과정, 레벨, 미션여야 함
  - 예외 발생 시 에러 문구 출력, 재입력
- [x] **크루 명단 파일 읽기**

### 2. 페어 매칭
- [ ] **페어 매칭**
  - 두명씩 매칭 (페어 매칭 대상이 홀수인 경우 한 페어는 3인으로 구성)
  - 같은 레벨에서 이미 페어를 맺은 크루와는 다시 페어로 매칭될 수 없음
  - 구현 방법
    - 이름 목록을 List<String> 형태로 준비
    - 목록의 순서를 랜덤으로 섞음 (`camp.nextstep.edu.missionutils.Randoms`의 shuffle 메서드)
    - 앞에서부터 순서대로 두명씩 페어
    - 홀수인 경우 마지막 남은 크루는 마지막 페어에 포함
    - 같은 레벨에서 이미 페어로 만난적이 있는 크루끼리 다시 페어로 매칭 된다면 다시 shuffle 부터
    - 3회 시도까지 매칭이 되지 않거나 매칭을 할 수 있는 경우의 수가 없으면 에러 메시지를 출력
- [x] **페어 매칭 결과 출력**

### 3. 페어 재매칭
- [ ] **페어 재매칭 시도 입력**
    - 입력 안내 문구 출력
    - 입력
    - **예외 처리**
        - 빈값 / 공백 불가
        - 네 또는 아니오
    - 예외 발생 시 에러 문구 출력, 재입력

### 4. 페어 초기화
- [ ] **페어 매칭 내역 초기화**

### 5. 종료
